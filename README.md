# DURHACK-2026
XericUnitedEagle team DURHACK 2026 repo

Pulse is "a QR code you can hear": a link played as near-silent sound, decoded by a microphone.

## Download the desktop app (Windows)

1. Go to the [latest release](https://github.com/danielyeoman04/DURHACK-2026/releases/latest) and download **Pulse-Setup-1.0.1.exe**.
2. Run it. Windows shows "Windows protected your PC" because the app is not code-signed: click **More info**, then **Run anyway**.
3. Pulse starts listening straight away. Closing the window keeps it listening from the tray icon.

It saves every link it hears and shows a notification. It never opens a link by itself.
Mac: build it on a Mac, see [desktop/README.md](desktop/README.md). No install needed on a phone: use the web app.
